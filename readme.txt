简单的安装方法: (以下每一步都非常关键,请仔细阅读)

  + 上传 ./upload 下的所有文件到服务器（其他目录不用上传）

  + 将服务器上 ./templates, ./attachments, ./customavatar, ./forumdata, ./forumdata/cache,
    ./forumdata/templates, ./forumdata/accesslogs 五个目录属性改为 777,否则无法继续
    安装或部分功能无法使用
  + 运行 install.php 根据提示安装程序,设置管理员账号

  + 如果提示您的 config.php 无法在线编辑,请在本地编辑好后用 FTP 上传

  + 关于 config.php 配置方式,其中数据库内容请咨询您的空间提供商,其他内容参考程序中
    给出的注释

  + 如果因 PHP 配置原因无法发送邮件,可修改 mail_config.php,选用其他的方式

  + 更详细的使用问题解答,请参考 FAQ 档(faq.txt)
