    === Discuz! 自定义帮助说明 ===

    从 Discuz! 2.0 开始提供了通过文本文件自定义使用帮助的功能,该功能使得用户在不
修改任何源程序的前提下,可以自由的添加各种帮助信息.
    本文档对该功能的相关要求和文件格式说明如下:
    
    1. 本功能使用模板目录下的 customfaq.lang.php 存储自定义帮助信息,如模板为默认
模板时,该文件的路径为 ./templates/default/customfaq.lang.php;

    2. 文件搜寻的原则遵循先自定后标准的方式,即首先搜索自定义模板(假设当前正在使用)
中的 customfaq.lang.php,如存在则读取,不存在则搜索默认模板下的该文件,如存在则读取,
不存在则不显示自定义帮助信息;

    3. customfaq.lang.php 是 PHP 程序,书写应该遵循 PHP 的语法规定,格式如下:

       ==========================================================================
	<?php

	$customfaq['title'] = '自定义帮助的标题';
	$customfaq['item'][] = array(
		'subject' => '自定义帮助的条目 1 的标题',
		'message' => '自定义帮助的条目 1 的内容'
		);

	$customfaq['item'][] = array(
		'subject' => '自定义帮助的条目 2 的标题',
		'message' => '自定义帮助的条目 2 的内容'
		);

	$customfaq['item'][] = array(
		'subject' => '自定义帮助的条目 3 的标题',
		'message' => '自定义帮助的条目 3 的内容'
		);
	
	// ... 以此类推
	
	?>
       ==========================================================================

    4. 标题和内容中如果出现单引号,无比将其加反斜杠变为 \',否则会导致错误信息;

    5. 标题和内容中可以使用 html 代码,简体中文版 Discuz! 压缩包中包含了一个自定义
帮助范例;

    6. 显示自定义帮助信息的链接为 faq.php?page=custom.
